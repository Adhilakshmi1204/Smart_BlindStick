# Smart_BlindStick
 Disabled individuals face challenges with independent mobility, limited hazard detection and lack real-time feedback. Current solutions also hinder caregivers from remotely monitoring the user’s location and safety effectively.In order to bulid the confidence of the visually impaired individuals to do their day to day activities on ther own without depending on theri family members or care takers.Here this Smart blind stick include object detection, image processing using YOLO V3,navigtion using GPS module withe the help of raspberry pi4.
